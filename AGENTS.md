# Spec-Driven Development (SDD) Enforcement

This project strictly follows the **Spec-Driven Development** methodology. 

Whenever you are asked to build a new feature, architecture, or backend module, you MUST NOT jump straight to writing code. Instead, you must follow the 5-step SDD process.

If the user gives a generic prompt to build something, politely remind them of the SDD process and ask if they would like to start with `/spec`.

For detailed instructions on the 5 steps and the available slash commands, activate the `sdd-workflow` skill.
